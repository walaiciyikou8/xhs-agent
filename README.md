# 小红薯 Agent

上传几张真实照片，自动写出能发的小红书标题、正文、标签和封面建议——不用花钱买模型额度。

**在线使用**：https://你的用户名.github.io/xhs-agent/

---

## 这是什么

一个纯前端的小红书内容工作台，单文件 HTML，打开就能用。核心是一条链路：

```
上传配图 → 云端转发口看图 → 生成标题/正文/标签/封面建议 → 存进素材库
```

之所以要"云端转发口"：智谱的看图模型是永久免费的，但它的接口不允许浏览器直接调用（跨域限制）。所以中间加了一层 Supabase Edge Function，由它代为请求，页面再取结果。

## 功能

- **工作台**：传图自动出文案，按内容类型（种草/测评/教程/避坑/清单）和语气人设（真实闺蜜/专业博主/搞笑嘴替/温柔治愈）切换
- **热点雷达**：按领域给出当日可蹭的话题
- **爆款拆解**：按赛道给出真实爆款案例和可复制的拍摄要点
- **周报**：填了数据就出诊断、拍摄改善建议和爆款对标
- **素材与草稿**：图片、笔记本地留存，可接浏览器扩展一键填发布页
- **多设备**：接 Supabase 后电脑和手机共用同一份数据

## 模型说明

| 用途 | 模型 | 成本 |
| --- | --- | --- |
| 看图写文案 | `glm-4.6v-flash` → `glm-4v-flash` → `glm-4.6v` | 前两个免费，最后一个约 0.3 分/次 |
| 纯文字（周报分析） | `glm-4.5-flash` / `glm-4.7-flash` | 免费 |

免费模型有并发限制，排队时转发口会自动换下一个；全部排不上时回落到本地模板引擎，不会卡死。

## 怎么用

1. 打开上面的在线地址（或本机 `index.html`）
2. 进设置页，点「智谱免费 · 云端转发」，把口令粘到 API Key 栏，保存并测试
3. 回工作台，拖入照片，点生成

口令只存在你自己的浏览器里，不上传、不进代码。

## 技术栈

- 单文件 HTML + 原生 JS，无框架、无构建依赖
- 数据：Supabase（Postgres + RLS），可选，不接也能离线用
- 模型转发：Supabase Edge Function（Deno），口令校验 + 失败自动降级
- 备用方案：本机 `serve.py`（Python 同源转发，适合不外网的情况）

## 一些边界

- 免费模型晚高峰会排队，第一次生成等 10–30 秒是正常的
- 生成的是**草稿**，发布前请自己过一遍事实和措辞，别直接发
- 页面里不含任何密钥；云端密钥存在 Supabase 项目的环境变量里
- 仅作个人内容创作辅助，发布请遵守平台规则
